# India Copilot

Build a modern AI web app called "GovCopilot" for Smart India Hackathon.

Create a responsive government dashboard with 5 modules:

1. AI Document Intelligence – Upload PDFs/DOCX, ask questions, AI answers with source citations (dummy data).

2. Workflow Copilot – Search government services and display step-by-step procedures, required documents, timeline, and checklist.

3. Policy Conflict Checker – Compare two uploaded policy documents and highlight conflicts, missing clauses, and compliance issues (demo data).

4. Decision Intelligence Dashboard – KPI cards, pending cases, citizen grievances, charts, AI insights, and recent activities.

5. AI Draft Generator – Generate official letters, notices, circulars, RTI replies, and office orders from prompts (sample output).

Design:

- Clean Government Copilot UI inspired by Microsoft Copilot.

- Blue/white theme with modern cards, icons, smooth animations, rounded corners, dark mode.

- Sidebar navigation, top search bar, chat interface, drag-and-drop upload, responsive layout.

Build a clickable frontend MVP with realistic sample data, polished UX, and demo-ready interactions. No backend or authentication.
